# Al-Farabi Global Symposium 2026

Сайт Глобального симпозиума аль-Фараби (6–7 ноября 2026, Алматы, КазНУ имени аль-Фараби) с личным
кабинетом участника и админкой оргкомитета.

## Что умеет

**Для участников (сайт на русском, казахском и английском, по умолчанию — английский)**
- заявка на участие — слушателем или докладчиком;
- личный кабинет: вход, регистрация, восстановление пароля, статус заявки;
- подача статей в сборник и журналы, доработка по замечаниям редакции; сумма публикационного взноса — для сведения;
- страницы «Докладчики» и «Программа» — из админки;
- карта мест проведения с отелями, кафе и остановками рядом, кнопка «Google Карты».

**Для оргкомитета (админка `/admin/`, на русском)**
- заявки: подтверждение, лист ожидания, отказ — участнику уходит письмо; выгрузка в Excel;
- статьи: скачивание рукописей, статус и комментарий автору;
- докладчики и программа по дням; на сайт попадает только то, что включил оргкомитет;
- настройки: приём заявок и статей, сроки, тексты «приём закрыт», суммы взносов, почта для уведомлений;
- роли сотрудников: Оргкомитет, Редакция, Администратор симпозиума.

## Устройство

```
al-farabi-symposium-2026 V2.html   исходный одностраничный сайт (не меняется)
backend/                           Django + Django REST Framework
  frontend/build_site.py           собирает рабочий сайт из исходного HTML + личный кабинет (cabinet.js / .css)
  accounts/  registrations/  papers/  speakers/  program/  siteconfig/   приложения
  templates/venue_map.html         страница карты мест проведения
  tests.py                         тесты
```

## Запуск (Windows)

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env                       # затем заполните .env
.venv\Scripts\python frontend\build_site.py  # собрать сайт
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py createsuperuser
.venv\Scripts\python manage.py runserver 127.0.0.1:8001
```

Сайт — http://127.0.0.1:8001/, админка — http://127.0.0.1:8001/admin/.
Тесты: `.venv\Scripts\python manage.py test tests`.

Подробно — API, настройки, роли, выкладка на сервер: [backend/README.md](backend/README.md).

## Безопасность

- Секреты (ключ Django, пароль почты) — только в `backend/.env`, в репозиторий он не попадает.
  База данных и загруженные файлы (`*.sqlite3`, `media/`) — тоже.
- На сервере (`DJANGO_DEBUG=false`) сайт не запустится без настоящего `DJANGO_SECRET_KEY`;
  включён переход на HTTPS, защищённые cookie, ограничение попыток входа в админку.
- Рукописи статей отдаются только автору и сотрудникам с правом просмотра.
